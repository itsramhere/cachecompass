# Literature comparison

Reviewed through 2026-10-09. Relevant full-text sections were read; extraction alone is not reading. PDF page numbers below are one-based, including any cover; printed pages are given where helpful. Bibliographic identities and primary links are in [BIBLIOGRAPHY.md](BIBLIOGRAPHY.md). Local PDFs, page text and hashes are indexed in [reading coverage](../configs/literature_review.json). All findings here belong to the cited work; none is a measurement of this prototype. Absence of a mechanism in the sections read is a bounded inference, not proof that it never exists.

| R09 Metastable Failures in the Wild, OSDI 2022, pp. 73–90; §2–3, PDF 3–6; §5.3, PDF 13 | Incident analysis plus experimental applications; look-aside cache example uses Memcached/MySQL. | Demand refill; experimentally remove hot data to trigger overload. Evaluation is co-located memory management; cross-node scaling deferred (§4.5). Changes to pool allocation must not be conflated with bucket ownership admission. |

The strongest next-phase controls are migration-before-cutover (R02-inspired), fixed incremental handover plus fixed warming, warmup-only adaptation, traffic-only adaptation, and budget-aware migration-before-cutover. Equal metadata, memory, coalescing, query mix, deadlines and pilot-tuning effort are required. Immediate cold remapping diagnoses the penalty; beating it alone would not establish a contribution. These policies are planned; detailed executable contracts belong to Phase 2.
